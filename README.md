# Soft things

自由创作毛绒娃娃，保留完整草稿、面料、涂色、表情和配件，并加入共享档案袋。

## 网站

网页文件在 `docs/`，使用 GitHub Pages main 分支 /docs 发布。请先完成并验证 Supabase 配置，再开放网站。

## 共享保存

1. 在 Supabase SQL Editor 运行 `supabase/setup.sql`。
2. 开启 Anonymous sign-ins。
3. 创建管理员用户，并在 `site_admins` 中添加其 User UID。
4. `docs/cloud-config.json` 只配置项目 URL 和公开 publishable key；不能放 Secret / service_role 密钥。
5. 朋友提交成功后作品才加入档案袋，失败会保留草稿并显示错误。完整设计和透明图片存入共享存储。

## 管理员本地 Blender 渲染

在本机安装 Blender，下载仓库 ZIP 并解压，双击 `local-render/start.command`，打开 http://127.0.0.1:5173/free/#family 。在页面底部“作品保存”登录管理员，选择未渲染娃娃点击“帮助渲染”。完成后更新共享档案中的原娃娃，保持同一个 ID 和完整过程，不新增重复娃娃。

当前电脑原有网页也已接入同一个 Supabase 项目。管理员可点击“同步这台设备已有的娃娃”，把浏览器中旧作品保存到共享档案。

作品与图片公开展示；只有作者和管理员可以更新作品，删除权限属于管理员。项目容量和服务可用性取决于 Supabase 服务，不代表永久无限存储。

## 验证状态

本地跨浏览器逻辑、失败重试与同 ID 渲染更新已通过模拟测试。真实匿名登录、共享文件上传/异端读取、文件清理及管理员权限升级拒绝已验证。项目所有者已运行数据库权限测试，确认访客不能覆盖/删除其他作品、管理员能更新朋友作品；测试数据已回滚。
